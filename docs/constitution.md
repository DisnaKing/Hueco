# Constitución de Hueco

Prevalece sobre AGENTS.md, MEMORY.md y `docs/`. Solo cambia con la aprobación del responsable del proyecto.

1. Cada instalación sirve a un solo comercio.
2. Una misma hora nunca se reserva dos veces.
3. El precio, la duración y las horas libres los calcula el servidor, nunca el navegador.
4. Los datos personales de los clientes no se muestran en público ni se escriben en los logs.
5. Una migración de base de datos ya aplicada nunca se modifica.
6. Un cambio no está terminado hasta que sus tests pasan y su documentación está al día.
